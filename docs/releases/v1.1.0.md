# WAAPI Skill v1.1.0

Reliability fixes and expanded workflow validation for existing Wwise
capabilities. Supported Wwise versions remain **2021.1–2025.1**; Python remains
**3.11–3.13**. This release does not add a new reflected API surface.

## Changes

- Generate Windows Python runner paths without JSON backslash ambiguity, while
  retaining exact command-copy, authorization and execution checks.
- Improve attenuation-curve declarations, bounded readback and typed target
  binding; preserve existing SFX source identity and Originals placement during
  replacement imports.
- Clarify import declarations and capability boundaries discovered by broader
  RTPC, attenuation, effect, music and reimport workflows.
- Add seven integration workflow families: localized reimport, same-basename
  media mapping, RTPC maintenance, attenuation curves, appended effects, music
  import and existing Stinger reference maintenance.
- Harden the test harness for Windows UTF-8, paths, process cleanup and large
  reviewer inputs. Separate independently proven business outcomes from minor
  notice wording differences without rewriting original verdicts.

## Install or update

```bash
npx skills add zcyh147/waapi-skill --skill waapi-skill
```

For the fixed release, download **waapi-skill-v1.1.0.zip** and extract its
`waapi-skill` folder into your agent's Skills directory. The bundle contains
the packaged Skill and MIT license; it excludes local configuration, Python
virtual environments, test projects and campaign evidence. GitHub's **Source
code** downloads contain the whole repository instead.

See the [README](https://github.com/zcyh147/waapi-skill/blob/v1.1.0/README.md)
or [中文说明](https://github.com/zcyh147/waapi-skill/blob/v1.1.0/README.zh-CN.md).

macOS and native Windows with Wwise 2022.1/2025.1; EXP22-M05 is a separate
capability-boundary check. This is not a single-candidate, all-green automated
matrix or exhaustive API/parameter coverage.

all business assertions and 55 command reconciliations passed. Raw results

wording discrepancy under the approved outcome-based policy. Source projects
were unchanged, passing sandboxes removed, failed evidence retained and owned
processes/jobs cleared. No failed root was regraded or replayed.

a retired-Composer transport fixture remains a documented nonblocking test
failure. Full Playlist/Transition authoring, audible playback acceptance and
detailed expansion phase timing are not established by this release.
