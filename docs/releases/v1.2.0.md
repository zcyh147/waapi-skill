# WAAPI Skill v1.2.0

Broader Wwise workflows, more complete parameter support, and lighter runtime checks. Supports Wwise **2021.1–2025.1** on macOS and Windows; Python remains **3.11–3.13**.

## Changes

- Fill gaps in object queries, property conditions, creation and editing, including independent Effect ShareSets and Game Parameter ranges.
- Expand supported music, import, SoundBank, runtime and Authoring workflows, with version-specific layout, window and model operations.
- Disclose valid choices and nested request shapes through the Gateway, with clearer errors and explicit host/version limitations.
- Keep live connections bound to saved configuration. Drafts and transactions reject connection changes; temporary host/port overrides are not supported.
- Reduce repeated queries, metadata reads and file scans. Large reads retain bounded pages, and saved Source-copy verification is explicitly optional.
- Simplify the English and Chinese READMEs, document accepted creation limits, and streamline developer tests. Project changes retain Preview, authorization and execute-once checks.

## Install or update

```bash
npx skills add zcyh147/waapi-skill --skill waapi-skill
```

For the fixed release, download **waapi-skill-v1.2.0.zip** and extract its `waapi-skill` folder into your agent's Skills directory. The bundle contains the packaged Skill and MIT license; it excludes local configuration, Python virtual environments, test projects and campaign evidence. GitHub's **Source code** downloads contain the whole repository instead. **SHA256SUMS** provides the install bundle's checksum.

Connection settings are stored outside the Skill folder. After updating, ask your Agent to check the configured Wwise version and connection. Existing Drafts or Previews may need to be recreated if their contracts have changed; do not replay a transaction with an uncertain execution result.

See the [README](https://github.com/zcyh147/waapi-skill/blob/v1.2.0/README.md) or [中文说明](https://github.com/zcyh147/waapi-skill/blob/v1.2.0/README.zh-CN.md).

## Validation and limits

The completed broad offline regression recorded **27,609 passed, 1 failed, 168 skipped and 47 deselected**. The remaining test-fixture timeout was fixed and checked separately. Later runtime cleanup and review fixes passed **283 targeted test executions**, including reruns; the final code preflight passed **838 tests**. These are distinct runs, not an all-green full regression on a single final candidate.

The release retains recorded real-Wwise and Agent evidence from the project. This expansion does not establish every operation on every platform, Wwise version or patch build. No additional full regression, Wwise or Fresh Agent campaign was run solely for publication.

Some creation operations remain outside the Skill, and some native operations have limited result verification. See the [known creation limits](https://github.com/zcyh147/waapi-skill/blob/v1.2.0/docs/plans/full-waapi-coverage/SPEC.md#user-approved-remaining-creation-limits--2026-10-29), [detailed coverage](https://github.com/zcyh147/waapi-skill/blob/v1.2.0/skills/waapi-skill/references/waapi-coverage.md), [test inventory](https://github.com/zcyh147/waapi-skill/blob/v1.2.0/tests/TEST_INVENTORY.md), and [final acceptance](https://github.com/zcyh147/waapi-skill/issues/195) for exact scope, candidates and retained limitations. Original failed results are preserved.
