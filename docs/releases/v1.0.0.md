# WAAPI Skill v1.0.0

First stable public release: use natural language to query, edit, and monitor
Wwise through a local, version-aware Gateway.

## Highlights

- Query and edit Wwise objects, import audio, work with Events, RTPCs and
  Switch assignments, generate SoundBanks, and monitor supported events.
- Gateway-owned parameter construction, Preview, authorization, one-time
  execution, and result verification.
- Wwise **2021.1–2025.1**, on macOS and Windows. Requires Python **3.11–3.13**
  and your own supported Wwise installation.

## Install

```bash
npx skills add zcyh147/waapi-skill --skill waapi-skill
```

For the fixed v1.0.0 package, download **waapi-skill-v1.0.0.zip** below and
extract its `waapi-skill` folder into your agent's Skills directory. The Skill
prepares its Python dependencies on first use. See the
[README](https://github.com/zcyh147/waapi-skill/blob/v1.0.0/README.md) or
[中文说明](https://github.com/zcyh147/waapi-skill/blob/v1.0.0/README.zh-CN.md).

The custom ZIP contains the Skill and MIT license, without local configuration,
virtual environments, test projects, or test evidence. GitHub's separate
**Source code** downloads contain the whole repository, not this install bundle.

## Validation and boundaries

Latest scoped macOS WwiseConsole regression: **65/65** across the five Wwise
versions, including explicit safety/unsupported boundaries. Program:
**5766 passed, 2 skipped**. Non-live: **11347 passed, 116 skipped**.
See the [test inventory](https://github.com/zcyh147/waapi-skill/blob/v1.0.0/tests/TEST_INVENTORY.md)
for exact candidates and historical cross-platform evidence. These are not
claims that every API/parameter combination was executed on both hosts.

Capabilities depend on Wwise version and host; unsupported requests stop with
an explicit boundary. Full Playlist/Transition authoring and audible playback
are not established by the CRUD tests. Start with `ask_before_changes` and
keep project backups.
